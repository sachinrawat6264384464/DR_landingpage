# 🎓 Dr. Arvind Sharma — Academic & Research Portfolio Website

A state-of-the-art, premium academic portfolio and research group website engineered for **Dr. Arvind Sharma**, Professor of Computer Science & Head of Department at the Global Institute of Technology. Built using modern web technologies including **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, **Lucide React**, and **Framer Motion**.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript (`.tsx`)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion (`whileInView`, `whileHover`, `whileTap`, `AnimatePresence`)
- **Typography**: Playfair Display (Serif) & Inter (Sans-Serif)

## 🚀 Quick Start & Local Development

### 1. Clone the repository
```bash
git clone https://github.com/sachinrawat6264384464/DR_landingpage.git
cd DR_landingpage
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.
